# MINXO TV — Professional Kino va Seriallar Telegram Boti

python-telegram-bot==21.6 asosida yaratilgan, kino/serial katalogi, mavsum-qismlar tizimi, ko'p qirrali qidiruv, sevimlilar, to'liq admin panel, majburiy obuna va Render uchun Flask keep-alive bilan ta'minlangan professional tizim.

## Ishga tushirish

1. .env fayliga BOT_TOKEN va vergul bilan ADMIN_IDS kiritiladi (masalan: ADMIN_IDS=12345678,87654321). 2. Python 3.10+ muhitida 'pip install -r requirements.txt' qilib, 'python bot.py' ishga tushiriladi. 3. Render Web Service-da PORT avtomatik olinadi va Flask keep-alive serveri orqali doimiy uxlab qolmasdan ishlaydi.

`python bot.py`
